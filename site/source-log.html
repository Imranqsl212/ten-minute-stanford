How to read the evidence

Official Stanford source

Raw facts and policy

ExploreCourses responses, Campus Map results, Bulletin guidance, Transportation rules and the Campus Access Guide come from Stanford-operated domains. Only this category supports claims about Stanford policy, guidance or official systems.

External open data

Route-network input

OpenStreetMap supplies the saved route-network snapshot and documentation for its tags and license. It is not an official Stanford source.

Third-party reference

API request pattern

The mentor-recommended GitHub package is not an official Stanford publication. It documents the XML request pattern and field names; it does not support Stanford policy claims or numerical results.

Editorial context

History, not current policy

Stanford Daily links and the historical Google Sheet supply attributed prior reporting and an AY 2021-22 schedule artifact. They are not current policy, analytical inputs or evidence of Winter 2026 student outcomes.

Derived result

Our calculations

Counts such as 27,197 sections, 283,079 possible pairs and the component-pair and subject-area percentages are not Stanford statistics. They are reproducible outputs linked to the checked-in tables, validation report and claim ledger.

Author-conducted reporting

27 student responses

People the authors identify as Stanford students supplied illustrative experiences, consequences and route comments. The linked sheet exported 26 rows; one earlier response absent from that export is retained in the normalized reporting file. This convenience sample is not an official Stanford source or a campus-wide estimate. The published survey summary contains the audited aggregate counts.

The route and schedule analysis has three public-data inputs: Stanford ExploreCourses responses, Stanford Campus Map responses and the saved OpenStreetMap snapshot. The 27-response survey is separate author-conducted reporting and is not an input to the route model. GitHub code, Stanford Daily pages and the historical schedule sheet supply no numerical result.

Primary data

Schedule

Stanford ExploreCourses

Winter 2026 class numbers, components, meeting dates, weekdays, times, room labels, enrollment and capacity came from Stanford's public XML responses. The source manifest lists all 253 exact request URLs and hashes; this AA response is one live endpoint example. Request construction follows the third-party mentor-recommended CourseConnection implementation; its XML classes served as a field reference.

Coordinates

Stanford Campus Map

Facility IDs, room and building search labels, addresses and coordinates. Stanford's Campus Map FAQ describes the map as maintained by Land, Buildings & Real Estate.

Route networks

OpenStreetMap

Highway-tagged ways and nodes were retrieved through the Overpass API and filtered separately into walking and directional bicycle networks. The response reports an OSM database timestamp of 2026-08-03T10:23:14Z. OSM separately documents the wheelchair and incline tags used in the accessibility-coverage check.

The verified local snapshot contains 580 ExploreCourses HTML responses, 253 ExploreCourses XML responses, 444 Campus Map responses and one OpenStreetMap response, for 1,278 active raw responses in total. Every active response has a source URL, retrieval time and SHA-256 digest recorded in the source manifest. The validation report records the section, meeting, route-network and OSM tag-coverage counts derived from those responses. Raw response bodies are omitted from Git because of size. The collector can repeat the requests, but a later collection cannot recover the historical Aug. 3 and Aug. 5 bodies if a source changes.

The accessibility-coverage check uses all 30,835 highway ways in the saved OSM snapshot as its denominator. Only 51 ways (0.17%) have a wheelchair tag and 128 (0.42%) have an incline tag. Missing tags do not mean inaccessible or flat; they mean the snapshot cannot support a defensible campus-wide wheelchair-time model. The exact counts and rates are in the validation report and claim ledger.

Context and framing

  • About ExploreCourses describes schedule coverage and the stated daily refresh cadence.
  • Stanford Academic Advising's course catalog guide defines LEC, DIS and other class components.
  • Stanford Student Services' enrollment guide explains combined cross-listed sections, shared times and places, and total enrollment.
  • Stanford SIRIS Common Terms defines class components, cross-listed classes and subject codes, including curricular-category exceptions.
  • Stanford Bulletin Unit of Credit guidance states that a class is assumed to end ten minutes early to allow movement to the next class.
  • Stanford Undergraduate Admission tips notes the common ten-minute class-change interval.
  • Stanford Bulletin standard meeting patterns describes common meeting times and their role in reducing schedule conflicts; its current grid is marked effective Autumn 2024. It also states that classroom assignment considers efficient use and room characteristics and sets a 75% enrollment-to-capacity threshold; it does not identify consecutive-student travel distance as an assignment objective.
  • Stanford bicycle laws state the 10 mph Pedestrian Zone maximum and list riding restrictions.
  • Stanford's Bikeways Map provides official campus bicycle-route context.
  • Stanford Campus Access Guide provides building-specific accessible entrance information.
  • Stanford Suggested Travel Routes provides official pedestrian and bicycle route guidance.
  • OpenStreetMap wheelchair-tag documentation states that wheelchair access has no default value and points to additional physical-way tags relevant to wheelchair routing.
  • OpenStreetMap incline-tag documentation defines the tag used to record a way's grade, slope or incline.
  • The Stanford Daily Data section supplies editorial-format comparison only; it does not support an analytical or Stanford factual claim.
  • Prior Daily reporting on overlapping class times supplies attributed historical context on the pre-pandemic 10-minute commuting break, the AY 2021-22 shift to 15-minute breaks and student experiences with partial schedule overlaps. It does not establish current policy or current student travel outcomes.
  • The AY 2021-22 meeting-pattern spreadsheet is a historical Google Sheet linked from the Daily story, which reported that the scheduling documents were provided by a University spokesperson. Its visible Opt 4 grid includes 60-minute starts at 8:30, 9:45 and 11:00 and 90-minute starts at 9:45 and 11:30, examples that display 15-minute intervals. It contains no current courses, rooms, co-enrollment or travel observations and is not treated as current official policy.
  • The Daily's submission page supplies publication-process context only.

The original context set was checked on Aug. 4, 2026; API, bicycle, access and historical schedule sources were checked on Aug. 5. Component, enrollment and SIRIS terminology sources were checked on Aug. 7. The student survey sheet was exported and checked on Aug. 12. Both Bulletin pages returned HTTP 200 during the final direct check, and their exact supporting text was present in the live HTML.
